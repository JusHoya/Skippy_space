# Skippy_space — Comprehensive Project Review (2026-06-10)

Multi-agent review: 8 subsystem mappers → 9 dimension finders → adversarial skeptic-panel verification (3 lenses for high/critical) → completeness critic. Run across three resumes; the authoritative result is the **union** of the verified findings: **1 critical, 17 high, ~70 medium, 16 low** (~104 unique issues after deduplicating cross-dimensional restatements). Findings below are deduplicated across dimensions and grouped by theme; each carries the primary `file:line`.

## 0. The headline: the app is dead on arrival, and the gates can't see it

**CRITICAL — Built sidecar crashes at module load** (`apps/agent-runtime/tsup.config.ts:13`)
`tsup` only inlines `@skippy/shared` (`noExternal`); `@skippy/memory` stays an *external* bare import in `dist/index.js`. `@skippy/memory`'s package exports point at raw `./src/index.ts`, whose internal specifiers use `.js` suffixes that Node's type-stripping never remaps to the real `.ts` files. The Tauri shell spawns exactly `node …/dist/index.js` (`sidecar.rs`, `Command::new("node")`), so since memory-jobs was wired in at Phase 3 (commit `330a5ea`, 2026-06-03) the sidecar throws `ERR_MODULE_NOT_FOUND` instantly and the supervisor restart-loops it every 2 s, forever. **Reproduced directly by three independent verifiers:** `node apps/agent-runtime/dist/index.js` fails at import time. The product has been unbootable for a week while every phase gate reports green.
**Fix:** add `@skippy/memory` to `noExternal` (it's a source-only workspace package — bundle it exactly like `@skippy/shared`). Then add a no-API-key boot smoke to `validate:phase3.5` + CI: build, spawn `node dist/index.js`, assert the 8 `board_spawned` envelopes arrive on stdout within ~10 s, kill. That one check catches this and any future external-dependency regression.

**Why nothing caught it — the validation gates are green-but-blind:**
- **CI lint is a no-op** (`.github/workflows/ci.yml:16`) — no package defines a `lint` script, so ESLint has never run despite a maintained flat config. The Rust step is disabled and no test suite runs on push.
- **Gates grep for source strings instead of asserting behavior** — `phase3-validate.mjs` checks `env.includes('TelemetrySpanEnvelope')` rather than round-tripping an envelope; the gated SDK board path has zero behavioral coverage; Phase 2's Zustand store probe was silently downgraded to a grep while the header still claims a behavior smoke test.
- **Playwright "visual" tests detect no regressions** (`tests/visual/gallery.spec.ts:42`) — screenshots are overwritten, never compared, and the HUD check passes on a blank canvas.
- **Only phase0/phase1 gates actually boot `dist`**, and they require a live `ANTHROPIC_API_KEY` + nondeterministic LLM output, so "all prior gates pass" is unverifiable offline/in CI — and they haven't been re-run since Phase 3.

> Net: the test pyramid is mostly string-presence checks. This is the root cause that let a load-crashing sidecar, a dead telemetry path, and a stateless orchestrator all ship "green."

## 1. The integrated app doesn't wire together (HIGH)

- **Rust Envelope enum never mirrored the 5 Phase 3 variants** (`apps/shell/src-tauri/src/envelope.rs:16`). The hand-mirrored enum stops at Phase 3-prep; it has no `telemetry_span`, `context_window`, `error_span`, `memory_job`, or `replay_session`. The sidecar emits all five; `sidecar.rs` strictly deserializes each stdout line and **demotes anything unknown to a debug-level Log envelope**. So the entire Phase 3 telemetry HUD (cost meter, tok/s, context bar, error feed), memory-job pulses, and replay session id are dead end-to-end in the real app. **Fix:** add the five variants, or make the shell forward any well-formed `{type, …}` object verbatim and let the renderer's zod be the single validator. Add a cross-language parity test.
- **Skippy has zero conversation memory** (`apps/agent-runtime/src/claude.ts:125`). `streamSkippyWithTools` builds `messages = [{role:'user', …}]` fresh every call; nothing persists the tail. PRD §5.2 specifies one long-running `query()` for the whole session and §5.3 promises SQLite-checkpoint rehydration — neither exists. Any follow-up ("yes, do that", "what did Engineering report?") hits a model with no history. **Fix:** keep a per-session `MessageParam[]` trimmed by token budget; serialize periodically so the 2 s restart can rehydrate.
- **StrictMode double channel subscription** (`apps/ui/src/lib/channel.ts:279`). `useEventChannel`'s cleanup is a no-op, so dev registers two live channels; `appendToken` (string concat) and `recordSpan` (cost add) are **not idempotent**, so every streamed token is duplicated and every turn double-bills the cost meter. Since the app only runs in dev today, users hit this every run. **Fix:** module-level singleton subscription, or make cleanup neuter the closed-over channel.

## 2. Gated SDK boards are a security hole (HIGH)

The `PHASE3_AGENTS_ENABLED` path is the intended production path, and it dismantles every safety rail the charters and PRD promise.

- **Path traversal in `obsidian_write_note`** (`apps/agent-runtime/src/mcp-handlers.ts:100`). `path.join(vaultRoot, args.path)` with `args.path` a model-controlled bare `z.string()`, no containment check; `writeNote` doesn't contain either (`mkdir` + atomic write). `../../…` escapes the vault → write-anywhere primitive driven by model output. **Fix:** `path.resolve` + `startsWith(vaultRoot + sep)` guard (reject absolute paths) in the handler *and* in `atomic.ts` so every writer is protected.
- **`bypassPermissions` hardcoded** (`apps/agent-runtime/src/sdk-board.ts:67`). All 8 charters declare `permission_mode: ask` (a required PRD §6.1 field) plus `tools`/`disallowed_tools`; the runtime reads none of them and passes `permissionMode: 'bypassPermissions'` with no allowlist, granting the SDK's full default Bash/file toolset unattended. This directly violates `agent_space/CLAUDE.md`'s "safety rails are welded shut" doctrine and means the no-grandchildren depth limit has zero enforcement (a board with Bash can spawn `claude` grandchildren). **Fix:** map charter `permission_mode`/`tools`/`disallowed_tools` into `query()` options; if headless truly needs more, require a separate explicit env opt-in and log it loudly.
- **append-only files are clobberable + provenance is fake** (`apps/agent-runtime/src/mcp-handlers.ts:83`). The "create or overwrite" tool has no guard against `agent_log.md` or `40_Daily/` targets (CLAUDE.md #5 / PRD §8.6 mandate append-only), and `authored_by` is hardcoded `'board.sdk'` so the audit trail never records which board wrote a note. **Fix:** reject append-only basenames/paths; thread the board id into the handler.
- **Untrusted vault/inbox content feeds write-capable agents** (`apps/agent-runtime/src/mcp-registry.ts:50`) — a prompt-injection vector with no trust boundary.
- **Vault git auto-commit runs a bare `git commit`** (`apps/shell/src-tauri/src/git_autocommit.rs:132`). It gates on and stages `vault/` but commits the *entire index* with no pathspec, so any user-staged code mid-session gets swept into a `chore(vault): auto-commit` — contradicting the module's own contract and PRD §8.2, and corrupting commit history. **Fix:** `git commit -m … -- vault/`; serialize the on-demand and interval paths behind a mutex.

Lower-severity security: CSP `null` + unscoped `shell:allow-execute` (`tauri.conf.json:26`) removes the webview/native barrier; replay JSONL stores unredacted prompts + output in plaintext (no scrubber exists); docker stacks bind all interfaces with default creds.

## 3. Memory pipeline — the Phase 3 flagship — has correctness bugs (HIGH/MED)

- **Link job freezes on the oldest 50 notes** (`packages/memory/src/jobs/link.ts:137`). `.slice(0, NODE_BUDGET)` of lexicographic readdir order; ULID filenames sort oldest-first, so once the vault passes 50 atomic facts every *new* fact is invisible to linking forever. The exit-gate e2e (one paper, ~10 notes) can't catch it. **Fix:** sort descending / track a high-water ULID; the "≤50 notes" bound should cap work per topic, not exclude the newest data.
- **Ingest hard-fails on external relative `.md` links** (`packages/memory/src/jobs/ingest.ts:84`). The verbatim external body hits `assertNoRelativeMdLinks`, which throws on `[x](./README.md)` etc. — the common case for scraped/exported content. The drop aborts at job 1, stays in `00_Inbox`, and is never retried. **Fix:** neutralize relative links in copied bodies (reuse the archival-mirror neutralizer); reserve the hard guard for agent-authored notes.
- **Inbox drops never retried after failure/restart** (`packages/memory/src/vault-watcher.ts:72`) — `ignoreInitial` + the seen-set make any failed ingest a permanent strand.
- **Smart Connections vector path is dead** (`packages/memory/src/vector-store.ts:130`) — cache keyed by vault path, lookups by bare ULID; an SC-only store reports `available=true` while `search()` always returns `[]`.
- **Topic-page read-modify-write outside the lock** (`packages/memory/src/jobs/distill.ts:407`) — concurrent pipeline runs lose links and clobber pages; the re-stamp also resets `created_at`, drops passthrough frontmatter, and mints a new ULID on invalid pages.
- **`daily.ts` emits unquoted ISO timestamps** (`packages/memory/src/daily.ts:71`) that YAML-parse back as `Date` objects → daily notes fail the §8.3 validator. (`daily.ts` is also a zero-consumer duplicate write path that bypasses validation entirely.)
- **`letta_append_archival` reports success when the durable vault mirror failed** (`mcp-handlers.ts:144`).

## 4. UI / PixiJS correctness (HIGH/MED)

- **`zoomBy` focus-pinning math is in the wrong coordinate space** (`apps/ui/src/stores/cameraStore.ts:94`). The codebase uses world-space pan (`host = hostW/2 + (world+pan)*scale`) but `zoomBy` applies the classic screen-space pin formula. Worked counterexample in the finding: the cursor point jumps to screen center instead of staying put. Every wheel-zoom drifts the map. **Fix:** invert the actual camera transform; add a round-trip unit test.
- **devicePixelRatio double-correction** (`apps/ui/src/scene/SceneRoot.tsx:321`). Pixi v8 `renderer.width` is already logical pixels; drag-box hit-testing and wheel-zoom divide it by DPR again. On Windows' default 125/150 % scaling, drag-select hit-tests at shifted positions and zoom focus is computed from the wrong center. **Fix:** drop the DPR divisions; use `host.clientWidth/Height`.
- **Walkers are never despawned** (`apps/ui/src/scene/SceneRoot.tsx:583`) — `void despawnWalker;` never runs; `WALKER_REF_STORE` retains destroyed Pixi containers → unbounded per-frame tick cost + container leak over a session.
- **`TerminalPane` leaks a live PTY** (`apps/ui/src/hud/TerminalPane.tsx:89`) when unmounted while `pty_open` is in flight — guaranteed by StrictMode on every dev boot.
- **Global Tab hijack** (`apps/ui/src/hud/Hotkeys.tsx:108`) — `preventDefault` on every unmodified Tab even with nothing to cycle, breaking keyboard nav HUD-wide.
- **A third of the PRD §7.7 hotkey surface is wired to nobody** (`apps/ui/src/hud/Hotkeys.tsx:138`) — camera reset is unreachable and the §7.4 strategic-zoom LOD system never executes.
- **`memory_job` envelopes dropped on the floor** (`apps/ui/src/lib/channel.ts:248`) and the fog seed is still the Phase-2 placeholder its own comment says Phase 3 replaces.

## 5. Shell / Rust (MED)

- **`pty_close` never terminates anything** (`apps/shell/src-tauri/src/pty.rs:252`) — the reader thread's `Arc` keeps the ConPTY master alive and the user-shell child handle is discarded at spawn; closed tabs leave processes running.
- **PTY reader corrupts multibyte UTF-8** (`apps/shell/src-tauri/src/pty.rs:376`) — bytes are decoded per 4096-byte read, so any multibyte character split across a chunk boundary becomes mojibake in the terminal (independent of ConPTY's own quirks). **Fix:** buffer the trailing incomplete UTF-8 sequence across reads, or decode lossily with a carry-over buffer.
- **PTY/lifecycle ordering races** — output emitted before `pty_subscribe` is silently dropped (`pty.rs:385`); `EventBus` drops one-shot lifecycle envelopes published before the renderer subscribes and lagged subscribers permanently lose state with no resync (`channel.rs:41`, broadcast lag drop at `:64`).
- **Blocking FS/ConPTY work on the Tauri async runtime** (`project_tree.rs:264`).
- **Silent prompt-loss after sidecar death** (`sidecar.rs:150`) — `write_line` returns `Ok` while the child is gone; queued lines dropped on restart. The renderer then sticks forever in "speaking…" with only a console-bound Log signalling the death (no PRD-promised rehydration/resync).
- **Bundled-resource path mismatch** (`sidecar.rs:86`) — production sidecar lookup checks paths Tauri 2 never produces (a *second*, packaging-time copy of the dead-sidecar problem).

## 6. Architecture / PRD drift (MED)

- **`delegation_complete` always reports `result:'success'`** (`apps/agent-runtime/src/board.ts:309`) even when SDK execution failed — the failure arm of the wire contract is unreachable.
- **Charter frontmatter is a dead contract** — `model`/`effort`/`tools`/`spawnable_task_agents` are never consumed (`modelRegistry.ts:38`); per-board models actually come from `BOARD_META` while a comment claims otherwise; the parser truncates nested maps at the first list item, so `core_memory_facts` is unparseable in all 13 charters and the Letta binding survives only by key order (`charter.ts:151`).
- **SDK gating is incoherent at module load** (`mcp-registry.ts:16`) — `sdk-board` claims a dynamic import keeps the SDK off the boot path, but `mcp-registry` statically imports it into the supervisor's load chain, so an SDK load failure crashes boot even with the gate off.
- **PRD §5.1 topology / §5.3 failure model unimplemented**, with load-bearing comments now factually false (`board.ts:9`); R-01 (the PRD's only Critical risk — 12 s SDK cold start) is unmitigated and the warm pool is an unreferenced no-op stub (`warmpool.ts:1`).
- **Source-of-truth discipline broken** — Phase 3.5 traces to no PRD section, code cites phantom OQ ids (OQ-18, OQ-D4-01..04) absent from §16, and §11.3-promised docs (`docs/changelog.md`, `docs/architecture.md`) don't exist (`docs/PRD.md:594/845`).
- **8-board + costume invariants** enforced only by hand-synced duplicate literals; the costume-parity gate `agent_space/CLAUDE.md` claims does not exist.

## 7. Persona / conventions (MED/LOW)

- **Staff Officers are never loaded or invocable** (`charter.ts:92`) yet Skippy's system prompt directs him to use them every turn.
- **Captain codename drift** (`packages/shared/src/boards.ts:28`) — `BOARD_META` says "Caret"/"Scribe"; charters say "Hammer"/"Scroll". The parity lint CLAUDE.md promises doesn't exist.
- **Distiller runs Haiku** (`memory-jobs.ts:86`) while PRD §8.5 and `distiller.md` mandate Sonnet.
- **`psych-monitor` charter falsely claims `disallowed_tools` is "enforced at the runtime layer"** (`agent_space/staff/psych-monitor.md:148`) — nothing consumes it, and its MCP servers include vault-write tools.
- **Hoya_Box sync ritual has no operational substrate** — the docs R-11's mitigation references don't exist.
- **Lint cron mints a new ULID proposal note every run** (`packages/memory/src/jobs/lint.ts:153`) with no dedupe/consumer/expiry → unbounded vault growth nothing reads.

## Suggested order of attack

1. **Unbreak boot** — `@skippy/memory` → `noExternal`; add the boot-smoke gate. (Without this nothing else is testable.)
2. **Make the gates real** — boot smoke + envelope round-trip parity (TS↔Rust) + turn on lint/Rust/tests in CI. This converts every other fix into something you can verify.
3. **Reconnect the wire** — add the 5 Phase 3 variants to `envelope.rs` (or pass-through unknown well-formed envelopes); fix the StrictMode double-subscribe. Now the telemetry/replay/memory HUD actually lights up.
4. **Close the SDK-board security holes** — path containment, charter-driven permissions, append-only guards, pathspec'd auto-commit. Do this before anyone sets `PHASE3_AGENTS_ENABLED=1`.
5. **Fix the memory pipeline** — link-budget ordering, ingest link-neutralization, inbox retry. This is the Phase 3 flagship; it's currently silently lossy past 50 notes.
6. **Give Skippy a conversation tail** — the orchestrator console can't hold a conversation without it.
7. UI math (zoom/DPR), PTY lifecycle, and the architecture/persona drift can follow.
